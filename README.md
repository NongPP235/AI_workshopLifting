# เว็บวิเคราะห์การยกของ · เวอร์ชัน 1.2

Backend สำหรับ Deploy: ดู DEPLOY_BACKEND.md ใช้ requirements-server.txt, serve.py และ Dockerfile พร้อมรหัสเข้าใช้, CORS, ลิงก์ผลลัพธ์แบบลงลายเซ็น และคิวจำกัดจำนวนงาน

รัน `./start.ps1` แล้วเปิด http://127.0.0.1:8000
เครื่องอื่นให้ติดตั้ง Python 3.12 และรัน `./setup.ps1` ก่อน

ไฟล์ `vendor/`, `models/`, `data/`, `dataset_for_test/`, วิดีโอ และผลทดสอบที่สร้างขึ้นถูกกันออกด้วย `.gitignore` หลัง clone ให้รัน setup.ps1 เพื่อดาวน์โหลด dependencies และโมเดลใหม่ หากต้องการรันชุดทดสอบ Dataset ให้วางคลิปต้นฉบับไว้ใน dataset_for_test/ ก่อน

Repository นี้เก็บ frontend ที่ static/ และ backend Python ที่ root การ Deploy frontend บน Netlify ใช้ Publish directory `static` และยังต้องเชื่อมกับ backend ที่รัน Python แยกต่างหาก

ใช้ฟังก์ชันจาก notebook ที่ส่งมาโดยตรง: MediaPipe Lite, Kalman filter, calibration 1.5 วินาที, solvePnP, มุมบิดตัว และตารางน้ำหนัก 4×3 ไม่เปลี่ยนสูตรเดิม
`model.py` สกัดเฉพาะฟังก์ชัน/ค่าคงที่จาก `notebook_source.py` ด้วย `build_model.py` โดยไม่รันเซลล์ติดตั้งหรือเซลล์สาธิต

การ์ดแสดงมุมบิดตัวและ H เฉลี่ยในเฟรมที่วัดมือได้ น้ำหนักต่ำสุดตลอดคลิป และจำนวนยกจากวิธี realtime ใน notebook ซึ่งตรงกับ overlay และคอลัมน์ lift_count_realtime ใน CSV ส่วน Robust แสดงเป็นข้อมูลเปรียบเทียบ

ต้องเห็นทั้งตัวและยืนนิ่งตอนต้นคลิป ผลลัพธ์ไม่ใช่ค่าตายตัวตามภาพตัวอย่าง ไม่มีการใช้ข้อมูลจำลอง
ไฟล์อัปโหลดและผลลัพธ์เก็บใน `data/` บนเครื่อง ไม่ลบอัตโนมัติ จำกัด 500 MB ต่อคลิป และประมวลผลทีละงาน
เลือกคลิปจาก Dataset บนหน้าเว็บได้โดยไม่ต้องอัปโหลดซ้ำ ระบบตั้งส่วนสูง S01=165, S02=183, S03=180, S04=178, S05=173 ซม. ตามข้อมูลผู้ใช้ คลิปที่ไม่มีรหัสผู้ทดสอบต้องกรอกส่วนสูงเอง

เพิ่มความคืบหน้ารายเฟรม การดาวน์โหลดวิดีโอ การกู้คืนงานหลังรีเฟรชและผลลัพธ์หลังเซิร์ฟเวอร์เริ่มใหม่ ข้อความผิดพลาดสำหรับคลิปสั้น/ไม่พบคน และการปิดไฟล์วิดีโอเมื่อประมวลผลล้มเหลว

ทดสอบ Dataset ทั้งชุดด้วย `python test_dataset.py` (ใช้ runtime เดียวกับ start.ps1) รายงานบันทึกใน `test-report-calibrated.json`; ทดสอบข้อมูลกรอกและกรณีผิดพลาดด้วย `python test_validation.py`
รายงานตรวจการประมวลผลครบคลิป วิดีโอที่อ่านกลับได้ CSV และ HTTP Range 206 สำหรับการเล่นวิดีโอ ไม่ใช่การยืนยันความแม่นยำเชิงเรขาคณิต: ยังไม่มีค่าจริงของ H/V/มุมหรือจำนวนยกที่ติดป้ายกำกับ

ยังไม่ได้เผยแพร่ขึ้นอินเทอร์เน็ต เนื่องจาก backend ใช้ Python/OpenCV/MediaPipe
